# Gather

Private, end-to-end encrypted announcements and chats for churches and youth groups.

- `site/` — the app (deployed to https://gather-church-app.netlify.app)
- `firebase/` — Firestore security rules
- `docs/` — operator guide (Korean)
- `site/small-groups.js` — church-scoped small group home, directory and administration (Phase 1)
- [Small Groups setup, permissions and tests](docs/small-groups.md)

Every push to `main` is deployed by Netlify automatically.
